# 3D Printed parts

The files in this folder are for the 3D printed parts of the build. 

Not all parts are usable as they are. Some parts are modified by sanding, cutting, sawing, etc.

The servo housing only fits the [Servo MG90S Micro Metal Gears 180 Degrees](https://www.otronic.nl/en/servo-mg90s-micro-metal-gears-180-degrees), but I had to cut open the left side wall to be able to fit the wires through

In the final build in the [README](../README.md), the slot insert and PIR shroud are not used.
